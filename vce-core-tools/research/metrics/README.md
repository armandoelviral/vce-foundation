# Research Metrics Framework (RMF)

The Research Metrics Framework evaluates the epistemic health of the VCE Research Program.

Its objective is not to measure productivity.

Its objective is to measure scientific maturity.

The framework evaluates:

- epistemic evolution
- evidence quality
- hypothesis revision
- methodological rigor
- reconstructability
- governance maturity

The framework intentionally avoids using publication count or documentation volume as primary indicators of scientific progress.

Knowledge quality always takes precedence over artifact quantity.
