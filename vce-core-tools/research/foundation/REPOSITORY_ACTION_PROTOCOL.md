# Repository Action Protocol (RAP)

Version: 1.0

Status: Permanent

---

## Purpose

Guarantee that every validated architectural discovery becomes a permanent repository artifact.

Conversation is exploratory.

Repository artifacts are authoritative.

---

## Rule

Every validated discovery shall conclude with a Repository Action Block.

The block specifies:

- Artifact
- Classification
- Repository Path
- Terminal Commands
- Promotion Status
- Dependencies
- Next Action

---

---

## Principle

No permanent architectural knowledge shall remain exclusively within conversation history.
