# Capability Registry Candidate

Version: 0.1

Status: Candidate

Classification: Architecture Candidate

---

## Purpose

Evaluate whether Institutional Capabilities require a dedicated governed registry or may be represented within the existing Knowledge Graph and Institutional Memory.

---

## Candidate Responsibilities

- Capability identity
- Version history
- Ownership
- Evidence references
- Applicable scope
- Dependencies
- Adoption state
- Monitoring metrics
- Governance decisions
- Deprecation and retirement

---

## Reduction Question

Can these responsibilities be fully represented by:

Institutional Memory

+

Knowledge Graph

+

Governance

without introducing a dedicated Capability Registry?

---

## Decision Rule

A dedicated registry shall exist only if it provides irreducible lifecycle or governance behavior.

---

## Validation

SP001 architecture and pilot operations.
