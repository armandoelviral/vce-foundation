# Reference Architecture v0.1

Version: 0.1

Status: Draft

Classification: Reference Architecture

# Purpose

Define the complete reference architecture for every Scientific Product developed under the VCE Research Program.

The architecture is domain-independent.

Vertical Packs extend it without modifying the Core.
