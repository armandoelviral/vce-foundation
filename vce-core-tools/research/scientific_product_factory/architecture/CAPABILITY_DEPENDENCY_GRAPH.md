# Capability Dependency Graph

Version: 0.1

Status: Draft

Classification: Architecture

---

# Purpose

Represent dependencies among Institutional Capabilities.

Capabilities shall evolve through explicit dependency relationships.

---

## Relationship Types

requires

extends

specializes

supersedes

supports

depends_on

---

## Rules

No cyclic capability dependencies.

Every Capability shall declare explicit upstream capabilities.

Capability impact analysis shall traverse the dependency graph.

Governance shall review dependency changes.

---

## Outputs

Capability lineage.

Impact reports.

Evolution planning.

Risk analysis.

Reuse analysis.
