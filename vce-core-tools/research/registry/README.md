# Research Registry

The Research Registry is the canonical index of epistemic artifacts in the VCE Research Program.

It tracks:

- Constitutional Decisions
- Design Hypotheses
- Scientific Hypotheses
- Conceptual Models
- Candidate Foundational Statements
- Accepted Principles
- Formal Theorems

Every artifact must declare:

- identifier
- category
- status
- maturity
- related Research Cycle
- evidence status
- review status
