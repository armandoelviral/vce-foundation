# Purpose

This document provides the structural map
of the Institute.

It answers one question:

"Where does each kind of knowledge belong?"

It is intended to help future researchers
understand the organization of the Institute
before studying its individual disciplines.

# Guiding Rule

Every document in the Institute should have
an explicit architectural home.

If a document has no obvious location,
either:

• the architecture is incomplete;

or

• the document belongs somewhere else.

Architectural ambiguity should trigger
observation before reorganization.

# Institute Philosophy

The Institute does not organize files.

The Institute organizes knowledge.
