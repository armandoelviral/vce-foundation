# Scientific Object Transitions

## Purpose

Scientific progress occurs through governed transitions affecting Scientific Objects and their relationships.

Transitions constitute first-class architectural entities.

---

# Transition

A transition represents an explicitly justified change affecting one or more Scientific Objects.

Transitions preserve reconstructability.

Transitions never occur implicitly.

---

# Canonical Transition Types

Create

Update

Promote

Demote

Merge

Split

Deprecate

Archive

Link

Unlink

---

# Transition Requirements

Every transition shall record:

- initiating evidence;
- responsible Research Cycle;
- justification;
- timestamp;
- resulting object state.

---

# Guiding Principle

Knowledge evolves through governed transitions.

The Corpus preserves those transitions.
