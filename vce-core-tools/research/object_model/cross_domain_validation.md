# Cross-Domain Validation

## Purpose

Evaluate whether the Scientific Object Evolution Model generalizes across multiple domains.

The objective is to discover domains where the model fails.

Confirmation is not the goal.

Falsification is preferred.

# Validation Criterion

The model survives only if each domain can be represented without introducing additional primitive concepts.

Otherwise, the missing primitive must be identified and justified.
