# Identity Invariants (Candidate)

## Purpose

This document identifies the minimal set of properties whose preservation maintains Scientific Object identity.

The objective is to distinguish identity from mutable attributes.

---

## Candidate Mutable Properties

- lifecycle state
- evidence
- relationships
- representations
- metadata

---

## Candidate Identity Invariants

- persistent identity
- scientific object type

Origin remains under investigation.

---

## Research Question

Which minimal invariant set uniquely preserves Scientific Object identity?

---

## Falsification Strategy

Attempt to construct two Scientific Objects sharing all candidate invariants while representing distinct epistemic entities.

If successful, additional identity invariants are required.

Conversely, if candidate invariants can change without producing a distinct Scientific Object, they should be removed.
