# Scientific Object Algebra Falsification Plan

## Purpose

This document defines how the candidate Scientific Object Algebra shall be challenged during RC-0002.

The objective is not to confirm the algebra.

The objective is to identify operations that cannot be represented using the current candidate operation set.

---

## Candidate Algebra Under Test

- SO-OP-001 — Instantiate
- SO-OP-002 — Observe
- SO-OP-003 — Relate
- SO-OP-004 — Transition
- SO-OP-005 — Revise
- SO-OP-006 — Derive
- SO-OP-007 — Compose
- SO-OP-008 — Deprecate

---

## Falsification Criterion

The candidate algebra is incomplete if a scientifically meaningful operation is found that cannot be represented as:

- one candidate operation;
- a valid composition of candidate operations;
- a specialization of an existing candidate operation.

---

## Initial Stress Tests

### ST-001 — Delete

Question:

Does scientific knowledge ever require deletion as a primitive operation?

Candidate resolution:

Deletion may be represented as Deprecate, Withdraw or Historical.

Status:

Open.

---

### ST-002 — Merge

Question:

Can merging two Scientific Objects be represented as Compose plus Deprecate?

Status:

Open.

---

### ST-003 — Split

Question:

Can splitting one Scientific Object into multiple objects be represented as Derive plus Revise?

Status:

Open.

---

### ST-004 — Contradict

Question:

Is contradiction a primitive operation or a Relationship?

Candidate resolution:

Contradiction appears to be a governed relationship.

Status:

Open.

---

### ST-005 — Promote

Question:

Is promotion a primitive operation or a Transition?

Candidate resolution:

Promotion appears to be a Transition.

Status:

Open.

---

### ST-006 — Refute

Question:

Is refutation a primitive operation or a composition of Observe, Relate and Transition?

Status:

Open.

---

### ST-007 — Externalize

Question:

Can a Scientific Object generate an external product, service or instrument using the current operation set?

Status:

Open.

---

## Expected Outcome

The algebra shall be refined only when a stress test demonstrates that the current operation set is insufficient.

No operation shall be added solely for semantic convenience.

---

## Guiding Principle

The preferred algebra is the smallest operation set capable of representing reconstructable scientific evolution.
