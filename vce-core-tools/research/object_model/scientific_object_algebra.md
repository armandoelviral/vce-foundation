# Scientific Object Algebra (Candidate)

## Purpose

The Scientific Object Algebra defines the minimal candidate operations capable of describing the lifecycle and evolution of Scientific Objects.

These operations are provisional and will be challenged throughout RC-0002.

---

## SO-OP-001 — Instantiate

Creates a new Scientific Object.

---

## SO-OP-002 — Observe

Incorporates new evidence while preserving object identity.

---

## SO-OP-003 — Relate

Creates a governed relationship between Scientific Objects.

---

## SO-OP-004 — Transition

Moves a Scientific Object from one valid lifecycle state to another.

---

## SO-OP-005 — Revise

Updates internal knowledge while preserving identity.

Candidate specialization of Transition.

---

## SO-OP-006 — Derive

Produces a new Scientific Object from one or more existing Scientific Objects.

---

## SO-OP-007 — Compose

Constructs higher-level Scientific Objects from governed compositions.

---

## SO-OP-008 — Deprecate

Terminates active evolution while preserving reconstructability.

---

## Open Question

Is this algebra complete?

RC-0002 will attempt to identify operations that cannot be represented using this candidate set.
