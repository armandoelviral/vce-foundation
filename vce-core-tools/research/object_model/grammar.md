# Scientific Object Grammar

## Purpose

This document defines the valid compositions among Scientific Objects.

The grammar governs how Scientific Objects may be connected to produce reconstructable scientific knowledge.

---

# Principle

Scientific knowledge is not an arbitrary graph.

Only governed compositions are valid.

---
