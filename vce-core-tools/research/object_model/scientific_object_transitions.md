# Scientific Object Transitions (Candidate)

## Purpose

Transitions describe governed changes between valid lifecycle states.

Transitions never modify Scientific Object identity.

Transitions are produced exclusively by approved Operations.

---

## Transition Model

Event

↓

Governance

↓

Operation

↓

Transition

↓

New State

---

## Candidate Transition Properties

### TR-001

Every Transition has exactly one source State.

---

### TR-002

Every Transition has exactly one destination State.

---

### TR-003

Transitions preserve Scientific Object identity.

---

### TR-004

Transitions must satisfy all applicable Governance Rules.

---

### TR-005

Transitions preserve reconstructable provenance.

---

### TR-006

Transitions are immutable historical events.
