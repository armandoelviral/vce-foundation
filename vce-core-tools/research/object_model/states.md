# Scientific Object States

## Purpose

Epistemic State represents the current scientific standing of a Scientific Object.

Unlike Type, State evolves through research.

---

# Canonical States

Candidate

Active

Supported

Accepted

Revised

Deprecated

Historical

---

# Transition Principle

State transitions require:

- evidence;
- architectural decision; or
- explicit governance.

Transitions are never implicit.

---

# Forbidden Transition

Deletion.

Scientific Objects preserve historical continuity.

Objects become Historical.

They are never destroyed.
