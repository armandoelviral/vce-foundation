# Scientific Object Events (Candidate)

## Purpose

Events describe occurrences that may affect Scientific Objects.

Events do not directly modify Scientific Objects.

They trigger governed operations.

## Event Processing

Events never directly change Scientific Objects.

Events trigger Scientific Object Operations.

Operations may trigger State Transitions.

Transitions preserve Identity Invariants.
