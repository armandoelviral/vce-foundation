# Architectural Dependency Graph

## Purpose

Identify the dependency relationships among architectural concepts.

Irreducibility shall not be evaluated in isolation.

It shall be evaluated relative to dependency structure.

---

## Candidate Nodes

Reality

Identity

Representation

State

Event

Operation

Transition

Governance

Scientific Object

Corpus

Research Cycle

---

## Dependency Analysis

Each node shall answer:

1. What concepts does this node require?

2. Which concepts require this node?

3. Can any dependency be removed?

4. Can multiple dependency paths be unified?

---

## Decision Rule

Architectural primitives should minimize dependency depth while maximizing explanatory coverage.
