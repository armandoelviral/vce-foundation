# Architectural Reduction Protocol (ARP)

Purpose

Continuously minimize architectural complexity.

Question

What concepts can be removed without reducing explanatory capability?

Protocol

Every major theory shall periodically undergo Architectural Reduction Audit.

Concepts failing irreducibility tests should be removed or merged.


---

## Additional Audit Criteria

### ARP-003 — Semantic Stability

Question

Does the concept preserve the same structural meaning across every domain in which it is applied?

If semantic meaning diverges across domains, the concept should be:

- redefined;
- decomposed;
- or eliminated.

---

### ARP-004 — Explanatory Density

Question

Does the concept explain additional domains without requiring semantic redefinition?

Concepts exhibiting increasing explanatory power while preserving semantic stability should be preferred over concepts requiring multiple incompatible meanings.
