# Comparative Framework Reviews

The objective of these reviews is not to summarize literature.

The objective is to compare how different scientific disciplines address the research questions investigated by the VCE Research Program.

Each framework is evaluated using a common structure.

The review seeks:

- conceptual overlap;
- methodological differences;
- complementary contributions;
- possible contradictions;
- opportunities for integration.

Novelty shall never be assumed.

Every comparison exists to determine whether VCE extends, integrates or merely reformulates existing work.
