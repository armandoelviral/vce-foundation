# Source Taxonomy

## Purpose

Scientific evidence originates from heterogeneous sources.

The objective of this taxonomy is to classify those sources before they enter the Knowledge Integration Pipeline.

Classification does not indicate quality.

It identifies origin, intended use and expected evidentiary contribution.

# Guiding Principle

Evidence quality depends on methodology.

It never depends solely on publication type.

Every source remains subject to critical review.
