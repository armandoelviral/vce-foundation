# Domain Invariants

Version: 0.1

---

INV-001

Every Case must reference exactly one Objective.

---

INV-002

Every Recommendation must originate from exactly one Case.

---

INV-003

Every Expert Decision must correspond to exactly one Recommendation.

---

INV-004

Every Operational Evidence must originate from an Expert Decision.

---

INV-005

Every Capability Candidate must originate from Operational Evidence.

---

INV-006

Every Governance Decision must evaluate exactly one Capability Candidate.

---

INV-007

Every Institutional Capability must originate from an approved Governance Decision.
