# Canonical Identifier Model

Version

1.0

Status

Draft

---

## Purpose

Define the immutable identifier model for the
Commerce Knowledge Platform.

Canonical Identifiers uniquely identify
knowledge concepts independently of names,
translations, implementations, or software
artifacts.

---

## Canonical Format

CKP-TERM-000001

---

## Identifier Components

CKP

Knowledge Platform Prefix.

TERM

Knowledge Object Type.

000001

Sequential Immutable Identifier.

---

## Properties

Globally Unique.

Immutable.

Never Reused.

Language Independent.

Implementation Independent.

Human Readable.

Machine Readable.

---

## Lifecycle

Allocated.

Approved.

Deprecated.

Retired.

Reserved identifiers shall never be reused.

---

## Constraints

Identifiers shall never change.

Names may change.

Definitions may evolve.

Identifiers remain permanent.

---

## Release Criteria

Canonical format defined.

Lifecycle defined.

Properties declared.

Constraints declared.
