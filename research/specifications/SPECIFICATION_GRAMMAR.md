# HAS Runtime Specification Grammar

Version

1.0

Status

Draft

---

The executable specification language consists
of six normative clauses.

Purpose

Defines why a concept exists.

Domain Definition

Defines what the concept is.

Runtime Semantics

Defines observable runtime behavior.

Constraints

Defines prohibited behavior.

Guaranteed Properties

Defines invariants preserved by every
conforming implementation.

Verification

Defines the executable contracts that
demonstrate conformance.

---

Normative Language

The following words have normative meaning.

Shall

Mandatory requirement.

Shall Not

Prohibited behavior.

May

Optional capability.

Undefined

Behavior intentionally left outside the
current specification.
